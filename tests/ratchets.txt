# The ratchets: tests that read the repository's own text (sources, docs, schemas) and hold
# a rule about it, run by `make ratchets` in seconds and first in `make merge-gate`, so a
# rule broken by a change fails before the suite's minutes rather than after them.
# Each line: a test target (`lib`, `bin`, or a file under tests/ without `.rs`), a tab, and
# the libtest path of one test, run with --exact; or `*`, a tab and the target's number of
# tests, for every test of that target. scripts/ratchets.sh runs them and fails unless each
# target ran exactly the tests it was given, that many for a `*` line; tests/ratchets.rs
# fails on a line whose target or test does not exist, or whose count is not the file's.
# A test target that lists the tracked tree through git is a `*` line here, so the reduced gate
# of a document-only diff runs it, or is excepted in tests/merge_gate.rs with its reason
# (which holds this).
